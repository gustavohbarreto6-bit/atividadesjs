# atividadesjs

📄 Projeto JavaScript – Exercícios Básicos

Este projeto contém páginas HTML simples utilizando JavaScript para interação com o usuário e um arquivo CSS para estilização básica. O objetivo é demonstrar conceitos iniciais de entrada de dados, manipulação de strings e operações matemáticas.

📂 Estrutura do Projeto
📁 projeto
 ├── index.html (Boas-vindas com prompt)
 ├── index.html (Concatenação de nome e sobrenome)
 ├── index.html (Somatória de números)
 └── style.css

🖥️ Funcionalidades
✅ 1. Programa de Boas-Vindas

Solicita o nome do usuário através de uma caixa de diálogo.

Exibe uma mensagem de saudação personalizada.

Pergunta se o usuário está bem.

✅ 2. Concatenação de Nome e Sobrenome

Possui um formulário para digitar:

Nome

Sobrenome

Ao clicar no botão Enviar, o sistema:

Junta o nome e sobrenome

Mostra uma mensagem de boas-vindas com o nome completo

✅ 3. Somatória de Números

Solicita dois números ao usuário.

Realiza a soma dos valores digitados.

Exibe o resultado na tela.

🎨 Estilização

O arquivo style.css define a aparência visual do projeto:

Cor de fundo personalizada para a página.

🚀 Tecnologias Utilizadas

HTML5

CSS3

JavaScript

▶️ Como Executar

Baixe ou clone o projeto.

Abra qualquer arquivo index.html em um navegador.

Interaja com as caixas de diálogo ou formulários.
